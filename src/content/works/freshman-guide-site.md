## 背景

面向四川大学新生，提供历年分数线、招生政策、专业介绍等信息的轻量 H5 站点，作为升学规划与家教服务的入口。

## 我的角色

设计与开发：页面结构、数据组织与 GitHub Pages 部署。

## 我做了什么

- 整理各省历年分数线、招生政策外链与专业介绍数据；
- 实现响应式单页 H5，支持微信分享二维码；
- 通过 GitHub Pages 上线并维护。

## 成果

- 已上线：`luoyedashi.github.io/scu-freshman-guide/`；
- 建立"数据 JSON 驱动 + 静态部署"的轻量站点模式。

## 反思

一个真正有用的工具站，关键是数据准确与更新机制——上线只是开始，维护才是日常。
