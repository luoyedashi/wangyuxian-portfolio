# 导航设计

## 主导航（6 项）

```text
首页 / 关于我 / 作品集 / 声音 / 摄影 / 联系我
```

- 桌面端：顶栏右侧水平导航；
- 移动端：汉堡菜单展开全屏导航；
- 「成长记录」V2 开放后加入主导航或页脚。

## 页脚导航

- 品牌标识 + 一句话定位；
- 链接：首页、关于我、作品集、声音电台、摄影画廊、联系我；
- 联系方式：邮箱、GitHub；
- 版权与隐私声明：© 2026 王钰贤 · 把想法落地成作品。

## 页面标题层级
- 首页 H1：王钰贤；
- 列表页 H1：作品集 / 声音电台 / 摄影画廊；
- 详情页 H1：作品/节目/专题标题；
- 分类页 H1：分类名（作品集 · 水利与工程）。
