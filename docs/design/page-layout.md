# 页面布局规范

## 栅格
- 内容最大宽度 1120px，边距 24px（移动端 20px）；
- 卡片网格：1 列（移动）/ 2 列（平板）/ 3 列（桌面）。

## 首页
- Hero 全宽，主视觉靠右或全幅背景（选摄影图）；
- 章节间距 96px（桌面）/ 64px（移动）。

## 列表页
- 标题 + 筛选条 + 卡片网格。

## 详情页
- 顶部封面（16:9），正文最大宽度 720px 居中；
- 元信息行（分类/时间/角色）；
- 章节：简介、背景、行动、成果、反思、材料链接。

## 摄影专题
- 顶部大封面 + 正文说明 + 图片瀑布/网格 + 灯箱。

## 联系页
- 说明 + 合作方向标签 + 联系方式卡片 + 简历按钮。
