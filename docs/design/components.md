# 组件设计

| 组件 | 说明 |
|---|---|
| Navbar | 固定顶栏；移动端汉堡菜单 |
| Footer | 品牌 + 导航 + 联系方式 + 版权 |
| Hero | 大标题 + 身份标签 + 副文案 + 双按钮 + 主视觉 |
| SectionHeading | 编号（01/02）+ 中文标题 + 可选副文案 |
| WorkCard | 封面、分类标签、标题、简介、时间 |
| FilterTabs | 全部分类筛选（客户端过滤） |
| AudioPlayer | 音频占位态：显示「音频整理中」 |
| Gallery | 图片网格，懒加载 |
| Lightbox | 点击放大、左右切换、关闭 |
| ContactForm | mailto 表单（无后端） |
| TagList | 标签列表 |
| Badge | 分类/状态小徽标 |
| Breadcrumbs | 详情页面包屑 |
| SEOHead | title/description/OG 注入 |
