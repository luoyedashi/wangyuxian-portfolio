# 核心受众与关注点

## 1. 老师 / 学院
- 关注：专业能力、主动性、成果意识、组织能力；
- 网站应展示：科研预演与综述、专业调研、大创方向、实践参与、认真与担当。

## 2. 组织 / 同学
- 关注：团学工作、宣传物料、策划执行、表达能力；
- 网站应展示：智慧招新系统、推文、凤凰展翅宣传、主题团日活动、实践团工作。

## 3. 合作方 / 商业伙伴
- 关注：商业分析、项目策划、执行落地能力；
- 网站应展示：家教双选小程序、可行性论证、新生指南站、行业调研。

## 4. 朋友 / 访问者 / 个人品牌
- 关注：摄影、声音、审美与个人气质；
- 网站应展示：摄影专题、声音节目（占位）、成长叙事、克制的个人表达。

## 内容基调
真诚、克制、有行动力；第一人称；不说空话；作品即证据。
