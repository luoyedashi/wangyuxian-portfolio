# 任务结果

## Task ID
PRI-001

## Agent 角色
隐私合规 Agent / Privacy & Compliance Agent

completed

## 摘要
建立网站公开内容白名单与禁止内容黑名单，为每类作品给出处理建议（可公开/需脱敏/需授权/不可公开）；设计内容模型的隐私字段与构建门禁；给出文案替代表达方式。审查标准：不确定默认不公开，隐私优先于美观与完整。

## 产出文件
- docs/privacy/content-policy.md
- docs/privacy/public-whitelist.md
- docs/privacy/review-report.md

## 禁止公开（黑名单）
1. 感情关系细节、暧昧分析、亲密关系进展；
2. 聊天记录截图或他人朋友圈分析；
3. 对具体同学、老师、朋友、学姐、女友的私人评价；
4. 心理低谷、情绪崩溃等过度私密内容；
5. 未授权的商业数据、公司内部资料、真实客户信息；
6. 他人照片未获授权；
7. 可能影响他人或组织名誉的评价；
8. 户口迁移证、高考录取统计表、成绩/绩点/排名等敏感个人信息；
9. 版权音乐（音乐文件夹全部曲目不得入站）；
10. 微信导出数据库与聊天记录文件。

## 允许公开（白名单，见 public-whitelist.md）
专业学习与科研预演（脱敏）、校园广播/节目信息（音频待补）、摄影作品（确认授权）、团学宣传物料、商业策划作品（脱敏）、AI 协作方法与开发实践（非代写）。

## 每类作品处理建议
| 内容类型 | 处理建议 |
|---|---|
| 科研预演（雅砻江等） | 可公开；注明数据为合成/预演，不得外推为实际精度 |
| 文献综述（GLOF） | 可公开；保留引用来源 |
| 实践日志/脚本/论证 | 需脱敏：去掉他人真实姓名、联系方式、经费明细可保留框架 |
| 宣传展示/推文 | 可公开；推文图片需确认无他人未授权正脸 |
| 商业小程序/系统 | 需脱敏：去除真实订单个人信息、密钥；展示思路与截图（截图需隐去姓名电话） |
| 竞赛项目 | 可公开项目简介与调研报告；如涉内部资料需脱敏 |
| 摄影 | 需授权：他人正脸且无授权 → 不用或裁剪；本人/授权图可公开 |
| 声音节目 | 结构可公开；音频上传前需复查内容 |
| 简历 | 手机号可选公开；发布前本人核对 |

## 隐私字段与门禁
```yaml
privacy:
  sensitivity: low | medium | high
  approved: true | false
  reviewer: PRI-001
  note: 审查说明
```
规则：`sensitivity: high` 默认不公开；`approved: false` 不进构建；涉及他人的照片/聊天/商业数据默认 pending。
