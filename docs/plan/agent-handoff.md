# Agent 交接规范

所有 Agent 输出遵循统一格式：

```markdown
# 任务结果
## Task ID / ## Agent 角色 / ## 状态
## 摘要（3-5 句）
## 产出文件（路径清单）
## 下一步建议（交接对象、缺料、风险）
## 待确认问题
```

## 依赖关系

```text
ORC-001 → PM-001 → (IA-001 ∥ PRI-001) → CON-001 → COPY-001 → DESIGN-001
         → DEV-001 → (DEV-002 + MEDIA-001) → SEO-001 → QA-001 → OPS-001
```

## 关键约束
- 中文输出，Markdown 格式；
- 隐私红线内容一律不得进入任何公开产出；
- 缺失素材以「待补清单」交接，不虚构；
- 每个交接点必须写明「下一步建议」。
