```text
作品集
从专业学习到团学实践，从商业项目到 AI 开发——这些作品记录了我如何把想法一步步落地。
```

## 分类描述
| 分类 | 描述 |
|---|---|
| 水利与工程 | 专业学习、行业调研与科研预演 |
| 商业与策划 | 商业项目、可行性分析与产品设计 |
| 校园与组织 | 团学、宣传、实践与组织工作 |

| AI 与技术 | AI 协作、开发实践与数据分析 |

## 作品详情模板（统一结构）
每个作品详情页包含：
- 标题
- 一句话简介
- 背景（为什么做）
- 我的角色（我在其中做什么）
- 我做了什么（行动）
- 成果（结果与指标）
- 反思（学到了什么）
